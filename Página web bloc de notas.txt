        <!-- HARDWARE -->

        <section class="seccion pagina-oculta" id="hardware">
            <div class="mini-titulo">Nivel 01 · Las partes físicas</div>
            <h2>¿Qué es el <span>hardware?</span></h2>

            <p>
                El hardware es el conjunto de partes físicas de un computador,
                es decir, todo lo que podemos ver y tocar. Cada componente
                cumple una función para que el equipo pueda trabajar.
            </p>

            <div class="tarjetas">
                <article class="tarjeta">
                    <span class="emoji">⌨️</span>
                    <h3>Teclado</h3>
                    <p>Permite escribir letras, números y otros caracteres.</p>
                </article>

                <article class="tarjeta">
                    <span class="emoji">🖱️</span>
                    <h3>Ratón o mouse</h3>
                    <p>Sirve para mover el cursor, seleccionar y abrir elementos.</p>
                </article>

                <article class="tarjeta">
                    <span class="emoji">🖥️</span>
                    <h3>Monitor</h3>
                    <p>Muestra imágenes, textos, videos y los resultados de las tareas.</p>
                </article>

                <article class="tarjeta">
                    <span class="emoji">🧠</span>
                    <h3>Procesador</h3>
                    <p>Ejecuta instrucciones y realiza operaciones para que el equipo funcione.</p>
                </article>

                <article class="tarjeta">
                    <span class="emoji">💾</span>
                    <h3>Memoria RAM</h3>
                    <p>Mantiene temporalmente los datos de los programas que están en uso.</p>
                </article>

                <article class="tarjeta">
                    <span class="emoji">📦</span>
                    <h3>Disco o SSD</h3>
                    <p>Guarda archivos, documentos, aplicaciones y el sistema operativo.</p>
                </article>
            </div>

            <div class="nota">
                <strong>Dato curioso:</strong> cuando juegas en el computador,
                el procesador, la memoria, la pantalla y otros componentes
                trabajan juntos para que puedas jugar.
            </div>
        </section>

        <!-- SOFTWARE -->

        <section class="seccion pagina-oculta" id="software">
            <div class="mini-titulo">Nivel 02 · Los programas</div>
            <h2>¿Qué es el <span>software?</span></h2>

            <p>
                El software es el conjunto de programas, aplicaciones e
                instrucciones que le indican al computador qué hacer.
                No podemos tocarlo físicamente, pero podemos utilizarlo
                a través de la pantalla.
            </p>

            <div class="tarjetas">
                <article class="tarjeta">
                    <span class="emoji">🪟</span>
                    <h3>Sistema operativo</h3>
                    <p>Administra los recursos del equipo y permite utilizarlo.</p>
                    <p><strong>Ejemplos:</strong> Windows, Linux y Android.</p>
                </article>

                <article class="tarjeta">
                    <span class="emoji">📝</span>
                    <h3>Programas de trabajo</h3>
                    <p>Ayudan a crear documentos, presentaciones y hojas de cálculo.</p>
                    <p><strong>Ejemplos:</strong> Word y PowerPoint.</p>
                </article>

                <article class="tarjeta">
                    <span class="emoji">🌐</span>
                    <h3>Navegadores</h3>
                    <p>Permiten visitar páginas web y buscar información en internet.</p>
                    <p><strong>Ejemplos:</strong> Chrome y Firefox.</p>
                </article>

                <article class="tarjeta">
                    <span class="emoji">🎮</span>
                    <h3>Videojuegos</h3>
                    <p>Son programas creados para jugar, explorar mundos y superar desafíos.</p>
                </article>

                <article class="tarjeta">
                    <span class="emoji">🎨</span>
                    <h3>Diseño y edición</h3>
                    <p>Permiten editar imágenes, crear ilustraciones y producir contenido.</p>
                </article>

                <article class="tarjeta">
                    <span class="emoji">🛡️</span>
                    <h3>Seguridad</h3>
                    <p>Ayuda a detectar amenazas y proteger la información del equipo.</p>
                </article>
            </div>

            <div class="nota">
                <strong>Ejemplo:</strong> puedes tocar el teclado, pero no puedes
                tocar físicamente el programa que utilizas para escribir una tarea.
                El teclado es hardware y el programa es software.
            </div>
        </section>

        <!-- CLASIFICACIÓN -->

        <section class="seccion pagina-oculta" id="clasificacion">
            <div class="mini-titulo">Nivel 03 · Tipos y funciones</div>
            <h2>Clasificación del <span>hardware y software</span></h2>

            <p class="subtitulo">
                Los componentes y programas se pueden organizar según la función
                que cumplen.
            </p>

            <h3>Tipos de hardware</h3>

            <div class="tarjetas">
                <article class="tarjeta">
                    <span class="emoji">🎤</span>
                    <h3>Entrada</h3>
                    <p>Permiten introducir información al computador.</p>
                    <p><strong>Ejemplos:</strong> teclado, mouse, micrófono y cámara.</p>
                </article>

                <article class="tarjeta">
                    <span class="emoji">🔊</span>
                    <h3>Salida</h3>
                    <p>Presentan la información que produce el equipo.</p>
                    <p><strong>Ejemplos:</strong> monitor, impresora y parlantes.</p>
                </article>

                <article class="tarjeta">
                    <span class="emoji">💽</span>
                    <h3>Almacenamiento</h3>
                    <p>Permiten guardar información para utilizarla después.</p>
                    <p><strong>Ejemplos:</strong> disco SSD, disco duro y memoria USB.</p>
                </article>

                <article class="tarjeta">
                    <span class="emoji">🧠</span>
                    <h3>Procesamiento</h3>
                    <p>Se encargan de ejecutar operaciones y procesar datos.</p>
                    <p><strong>Ejemplo:</strong> el procesador o CPU.</p>
                </article>
            </div>

            <h3 style="margin-top: 30px;">Tipos de software</h3>

            <div class="tarjetas">
                <article class="tarjeta">
                    <span class="emoji">⚙️</span>
                    <h3>Software de sistema</h3>
                    <p>Permite que el computador funcione y administra sus recursos.</p>
                    <p><strong>Ejemplo:</strong> Windows.</p>
                </article>

                <article class="tarjeta">
                    <span class="emoji">📚</span>
                    <h3>Software de aplicación</h3>
                    <p>Ayuda a realizar actividades concretas, como escribir o dibujar.</p>
                    <p><strong>Ejemplo:</strong> Word.</p>
                </article>

                <article class="tarjeta">
                    <span class="emoji">💻</span>
                    <h3>Software de programación</h3>
                    <p>Incluye herramientas para crear y probar otros programas.</p>
                    <p><strong>Ejemplos:</strong> editores de código y compiladores.</p>
                </article>
            </div>
        </section>

        // CAMBIO ENTRE PESTAÑAS

        const pestanas = document.querySelectorAll(".pestana");

        const paginas = {
            inicio: ["inicio", "introduccion"],
            hardware: ["hardware"],
            software: ["software"],
            clasificacion: ["clasificacion"],
            comparacion: ["comparacion"],
            juego: ["juego"],
            reto: ["reto"]
        };

        const elementos = [
            document.getElementById("inicio"),
            document.getElementById("introduccion"),
            ...document.querySelectorAll(".seccion")
        ];

        function mostrarPagina(nombre) {
            if (!paginas[nombre]) {
                return;
            }

            // Ocultar todas las páginas
            elementos.forEach(elemento => {
                elemento.classList.add("pagina-oculta");
            });

            // Mostrar solo el contenido de la pestaña seleccionada
            paginas[nombre].forEach(id => {
                const elemento = document.getElementById(id);

                if (elemento) {
                    elemento.classList.remove("pagina-oculta");
                }
            });

            // Marcar la pestaña seleccionada
            pestanas.forEach(pestana => {
                const seleccionada =
                    pestana.dataset.pagina === nombre;

                pestana.classList.toggle("activa", seleccionada);
                pestana.setAttribute(
                    "aria-pressed",
                    seleccionada ? "true" : "false"
                );
            });

            // Volver al inicio de la página
            window.scrollTo({
                top: 0,
                behavior: "smooth"
            });
        }

        pestanas.forEach(pestana => {
            pestana.addEventListener("click", () => {
                mostrarPagina(pestana.dataset.pagina);
            });
        });

        // Abrir Inicio al cargar la página
        mostrarPagina("inicio");


        // CUESTIONARIO INTERACTIVO

        const cuestionario = document.getElementById("cuestionario");
        const resultado = document.getElementById("resultado");

        const respuestasCorrectas = {
            p1: "b",
            p2: "c",
            p3: "b",
            p4: "a",
            p5: "b"
        };

        cuestionario.addEventListener("submit", function(evento) {
            evento.preventDefault();

            let puntos = 0;
            const total = Object.keys(respuestasCorrectas).length;

            for (const pregunta in respuestasCorrectas) {
                const seleccionada = cuestionario.querySelector(
                    'input[name="' + pregunta + '"]:checked'
                );

                if (
                    seleccionada &&
                    seleccionada.value === respuestasCorrectas[pregunta]
                ) {
                    puntos++;
                }
            }

            resultado.style.display = "block";

            if (puntos === total) {
                resultado.className = "correcto";
                resultado.textContent =
                    "🏆 ¡Excelente! Obtuviste " + puntos + " de " + total +
                    ". ¡Dominas los conceptos de hardware y software!";
            } else if (puntos >= 3) {
                resultado.className = "correcto";
                resultado.textContent =
                    "👏 ¡Vas muy bien! Obtuviste " + puntos + " de " + total +
                    ". Repasa las respuestas que te faltaron e inténtalo otra vez.";
            } else {
                resultado.className = "incorrecto";
                resultado.textContent =
                    "💪 Obtuviste " + puntos + " de " + total +
                    ". ¡No te rindas! Revisa las pestañas de aprendizaje y vuelve a intentarlo.";
            }

            resultado.scrollIntoView({
                behavior: "smooth",
                block: "center"
            });
        });

        // Limpiar el resultado cuando se reinicie el cuestionario
        cuestionario.addEventListener("reset", function() {
            resultado.style.display = "none";
            resultado.textContent = "";
            resultado.className = "";
        });
